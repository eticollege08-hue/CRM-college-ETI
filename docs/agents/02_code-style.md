## Стиль коду

- **Індентифікація**: 4 пробіли.
- **Лапки**: подвійні (`"`).
- **Точки з комами** та **кінцеві коми** у багаторядкових об’єктах/масивах.
- **Імпорт**: порядок → зовнішні, внутрішні alias, відносні; `import type` окремо. Для ESM додавайте `.js` розширення.
- **Типи**: `unknown` → звуження, `no-explicit-any`, `consistent-type-imports`.
- **Імена**: PascalCase для класів, camelCase для змінних/методів, UPPER_SNAKE_CASE для констант.
- **Коментарі**: пояснюють причину, а не опис коду.
